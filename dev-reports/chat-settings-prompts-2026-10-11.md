# 消息时间、设置简化与 Agent 提示词自测记录

2026-10-11 已完成修改并部署到主系统 http://localhost:3000；真实 API 自测环境 http://localhost:3600 同步更新。

## 修改结果

- 所有用户消息、助手回复及自动交付报告均显示原消息创建时间，格式 `YYYY-MM-DD HH:mm:ss`，按浏览器本地时区显示。旧备份缺失或无效时间显示“时间未知”，避免编造时间或导致聊天页面崩溃。
- 设置删除“实际调用与上下文”、刷新和展开记录功能，并删除该界面的相关读取请求。入口改为“设置”；模型、四类提示词及上下文管理仍可使用。
- 审查系统身份、主会话工作流、逐人核验、浏览器操作、文字核验、候选排序及压缩指令，统一当前规则。历史默认字符串仅用于配置迁移，不再通过拼接历史工作流生成当前提示词。

## 提示词修正

| 问题 | 当前规则 |
| --- | --- |
| 通用系统身份同时用于主会话和核验，容易把规划职责带入子流程 | 主会话调度；候选排序只决定顺序；逐人核验仅提交当前候选的证据和判断；能力以本轮工具集合为准 |
| 默认 `auto`、强制网页访问和人工占用桌面的规则分散 | `text` 不打开浏览器；`auto` 可复用可靠文字；`browser` 需要本轮本人主页观察；人工期间可登记全部工作，网页核验排队，文字和仅复用证据的补标继续 |
| 文字核验要求“当前主页原文”，容易与 API 来源混淆 | 本人主页原文可以来自 WaveSurge 采集或实际页面观察；必须核对来源、归属和采集时间，不能声称旧文字是本轮网页访问 |
| 筛选、标注、合格与入选的语义容易相互覆盖 | 条件逐项判断；画像提交实际值与证据；补标保留原判断和入选；研究、Campaign 预选、最终分配及补标任务分别解释计数 |
| 压缩被描述为只处理“已完成批次”，与实际按旧对话边界选取不一致 | 只概括程序选定的历史；后台工作可能仍运行，必须保留未完成请求，历史状态不替代实时数据库事实 |
| 付费描述容易暗示获得同意后即可使用不存在的工具 | 当前工具不支持平台付费搜索和外联；不能因用户同意而声称已付款、搜索或联系 |

四份旧默认提示词按原值精确匹配升级，配置版本只增加一次；重复启动不重复迁移，逐字段保留用户定制与模型配置。旧默认字符串已与修改前源码逐一对照。
