# 族裔资料核对与候选交付测试方案

本轮验证取消“必须本人亲口自述”的入选门槛。明确记载族裔的可靠文字资料可单列核对；缺少资料时保存待人工确认，继续筛选其他必选条件，不从照片、肤色、姓名或所在地推测族裔。已保存研究和历史结论保留原样。

## 程序与模型验证

- 范围登记：族裔原要求保留为核对项；地区、粉丝、个人身份及视觉条件保持。比赛体验、族裔话题、白色衣物不误分类；混合条件要求拆开。
- 判定：资料不足不阻断候选；其他必选条件不足仍待核实、不符仍排除。明确资料证明族裔不符者排除，模型猜测不能成为族裔事实。
- 来源：本人简介及有归属证明的可靠资料可提供明确记录，不要求第一人称“我是白人”。受控来源用例与真实开放搜索分开标明。
- 持久化：同一调用重放不新增研究，历史范围不改写；Campaign、补标和重新核验采用对应原研究范围。
- 交付：页面、单组及综合HTML、CSV和聊天均保留核验范围与待人工确认项，不混淆原始要求和已确认事实。
- 默认提示词升级，模型配置和自定义提示词保留；登录/验证时的用户确认与同一VNC接管协议保持。

运行完整单元/集成测试、类型检查、构建，以及隔离Docker中的浏览器回归。受控数据仅用于协议和回归验证。

通过 `http://101.201.237.219:33332/` 登录、填写消息并点击发送。输入不指定账号或检索词，由主Agent形成范围并选择检索词，调用实际WaveSurge接口及已配置模型。

固定输入：
