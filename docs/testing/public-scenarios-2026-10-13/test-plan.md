# 公网多场景端到端验收方案

日期：2026-10-13，Asia/Shanghai。入口：http://101.201.237.219:33332/。

验证用户自然语言描述不同创作者目标后，主 Agent 自行选择检索关键词，通过真实 WaveSurge API 和实际配置的模型完成逐人分析、保存画像、统计与交付。两个场景均不指定账号，不注入候选，不使用受控 API 返回。

| 场景 | 固定验收范围 | 目标与预算 |
|---|---|---|
| 跑步训练与参赛体验 | Instagram；1万–10万粉丝；地区不限；个人第一人称训练／马拉松／越野跑体验；排除品牌、店铺、赛事机构官方、明星及搬运；文字核验 | 目标3人；分析12人；基础资料80人 |
| 家用咖啡制作体验 | Instagram；1万–10万粉丝；地区不限；个人第一人称在家手冲／意式制作体验；排除品牌、咖啡店、器材商、机构官方、明星及搬运；文字核验 | 目标2人；分析12人；基础资料80人 |

每个场景通过实际公网浏览器登录、填写消息并点击发送，检查HTTP 201、持久范围、Agent生成关键词及无指定账号。终态记录实际核验、合格、入选与基础排除人数，不用搜索返回数量替代入选数。逐条查看入选条件、理由、原始来源摘录和画像标签；检查聊天自动报告、结果查询过滤、点击CSV与离线HTML下载，刷新后仍保留任务和结果，浏览器无未处理异常。

两项运行期间，通过同一公网页面发送一次只查询进度的补充消息。核对答复、前后保存的范围、研究任务总数和任务ID；查询不应重复登记、取消或改变已授权条件。

场景输入与断言在执行前固定，存于 `validation/2026-10-13/public-scenarios/scenarios.json`。任务未达到目标时保留实际结果，不修改条件或已有数据使断言通过。不同新任务可并行登记；每个请求拥有独立范围，其他任务保留。系统默认登录验证的人工确认与VNC交接保持原设置，本轮两个文字场景不要求第三方页面登录。

本轮以真实任务和公网浏览器证据为验收基础。此前单元／集成／有头端到端结果作为发布版本的回归背景单独注明，不伪称本轮重新执行。
