日期：2026-10-13，Asia/Shanghai。访问 [公网工作室](http://101.201.237.219:33332/)，使用原管理员密码。

## 验收结论

**实测入选：跑步训练与参赛体验3位，家用咖啡制作体验2位，均达到本次用例目标。** 从公网浏览器发送自然语言需求，由主Agent自行选择关键词，读取WaveSurge实际资料、逐人调用模型核验、保存画像和结果，并在聊天中自动交付综合报告及CSV。

本次测试范围：Instagram公开文字核验，粉丝1万–10万、地区不限，内容时间范围为已公开资料；输入采用开放搜索，由Agent生成检索词。验证内容包括运行中续聊、标签精确查询、逐条分组归属、页面与导出一致性、实际下载及刷新后持久化。

| 场景 | 主Agent生成的检索词 | 基础资料读取／排除 | 逐人核验 | 合格／入选／目标 | 任务终态 |
|---|---|---:|---:|---|---|
| 跑步训练与参赛体验 | `runner / marathon / trailrunner` | 28／17 | 11 | 3／3／3 | completed |
| 家用咖啡制作体验 | `homebarista / pourover / espresso` | 51／46 | 5 | 2／2／2 | completed |

合计读取79个账号基础资料、基础排除63个，逐人核验16个；5个合格且入选、4个待核实、7个不符合。综合报告对应2组、16条核验记录、5位去重入选者，各组和逐条归属清晰。[综合报告](http://101.201.237.219:33332/api/work-batches/ba652d587214e85a3a31509da4d1062d/report) · [综合CSV](http://101.201.237.219:33332/api/work-batches/ba652d587214e85a3a31509da4d1062d/report?format=csv)。报告接口需要先登录工作室。

## 程序与Agent执行流程

```mermaid
flowchart TD
  U["公网用户发送自然语言需求或执行中补充"] --> UI["前端生成幂等消息编号并 POST /api/messages"]
  UI --> IN["鉴权、校验，保存消息与待处理输入"]
  IN --> MAIN["主 Agent：当前真实任务事实＋最新消息＋历史上下文"]
  MAIN --> PLAN["模型理解人数、平台、条件、预算，生成检索词"]
  PLAN --> TOOL["start_research：持久保存固定范围和交付批次"]
  MAIN -->|进度查询| STATE["读取当前任务状态，回复后原工作继续"]
  TOOL --> WORK["后台研究执行器，主对话继续接收消息"]
  WORK --> SEARCH["GET search_users：账号列表、游标和去重"]
  SEARCH --> PROFILE["GET fetch_user_info_by_username_v2：本人ID、简介、粉丝数"]
  PROFILE --> BASE{"粉丝范围可行？"}
  BASE -->|否| EX["累计基础排除，保留读取位置并继续"]
  EX --> WORK
  BASE -->|是| POSTS["GET fetch_user_posts，必要时 GET fetch_post_info"]
  POSTS --> RAW["保存原始资料、帖文、媒体引用、发表与采集时间"]
  RAW --> VERIFY["本轮逐人模型核验：个人身份、第一人称实际体验、内容画像"]
  VERIFY --> CHECK["校验三态判断、本人归属、证据引用与基础事实"]
  CHECK --> SAVE["SQLite保存结果、标签和审计记录"]
  SAVE --> COUNT["分别计算核验、合格及配额内入选"]
  COUNT --> END{"达到人数目标或预算边界？"}
  END -->|继续| WORK
  END -->|结束| DONE["保存各研究实际终态与人数"]
  DONE --> BATCH{"该交付批次全部工作结束？"}
  BATCH -->|尚未| WAIT["已有结果可查看，等待剩余研究"]
  WAIT --> BATCH
  BATCH -->|是| DELIVERY["自动在聊天交付子报告、综合HTML及CSV"]
  SAVE --> QUERY["结果页按实际标签、平台和判断查询"]
  QUERY --> EXPORT["相同查询范围的在线报告、CSV与离线HTML"]
  DELIVERY --> U
  EXPORT --> U
  STATE --> U
```

本轮走公开文字核验路径。系统的其他核验模式及默认人工确认、同一有头浏览器VNC接管、交还后重新观察，见[架构与Agent设计](../../architecture.md)及[容器桌面协议](../../container-computer-use.md)。
