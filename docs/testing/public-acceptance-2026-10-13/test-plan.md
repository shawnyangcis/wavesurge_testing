# 公网发布测试方案

本轮以原交付地址 HTTP/IP 环境、真实 WaveSurge Token、真实配置模型和自然语言输入为业务验证来源。私密配置与管理员密码仅从本地环境／持久卷读取，不进入报告。原研究和原记录保留。

| 项 | 操作 | 通过标准 |
|---|---|---|
| HTTP 发送 | 从原公网地址登录，在 `isSecureContext=false`、无 `randomUUID` 的浏览器发送 | 后端 201、消息进入数据库并在 UI 展示；错误可见；重试幂等 |
| 新词开放检索 | `booknerd / booklover / bibliophile / geeky`，无 handles | 真实 GET 返回账号，后续逐人取得 profile、posts、details；不预埋名单，不隐藏来源错误 |
| 严格外观用例 A | 目标1人，欧美所在地、1万–10万粉丝、本人形象＋日常框架镜＋个人消费者体验 | 必选全部 match、每条理由有实际来源、视觉有已观察且归属确认截图；静物／墨镜不入选；未达标如实 partial |
| 基础文字用例 B | 目标2人、地区不限、个人阅读消费者体验；文字核验＋画像 | 实际开放数据达到2人并 completed；查看逐人理由／标签，聊天自动交付 HTML 与 CSV。不能把这2人替代外观名单 |
| 发布后严格 C | generic `bookworm`，同样严格口径、目标1人，不指定账号 | 开放检索完成1/1；实际查看本人持书＋透明框架镜截图，核对原帖归属、来源时间及所在地声明；封面不说成照片帖 |
| 发布后晚到文字 D | C 的慢浏览器工作开始后再自然发送 B 同口径消息 | D完成2/2时C仍在运行；自动交付和其他任务均保存，不以受控并发测试替代真实验证 |
| 运行中续聊 | A 真正运行时发送“继续原任务，查进度，严格条件保留” | 真实工具进度，无新建／取消／降条件；其他工作保存；终态报告仍交付 |
| 报告 | 公网打开在线 HTML、加载截图、点击下载 CSV／离线 HTML | 认证有效；人数、逐人判断、入选、分组一致；在线截图懒加载，离线截图内嵌；无控制台错误 |
| 人工交接 | 独立受控登录挑战、真实 LLM＋有头浏览器＋noVNC | Agent 说明原因，用户确认后接管，交还后重新观察原候选；当前挑战跳过不改变以后默认许可 |
| 重核验许可 | 原研究false、父在途override、子任务独立override；对照默认true其他研究 | 浏览器运行守卫与对外任务事实一致；当前子任务可修改许可，只释放同一子任务协助，父任务和其他桌面授权保留 |
| 归属负例 | 未确认关联网站、链接记录、来源错误 | 无法独自支持本人条件 match 或正向画像标签；有证明的关联网站路径仍可用 |
| 地区负例 | 明确 SF Bay Area／San Diego、装饰符号；对比旗帜、旅行、受众、Springfield | 地点原文及证据保留；明确声明可解析；国籍旗帜和不明地点不推断 |
| 真实错误地区修订 | 通过公网对 C 已有 bookwormcentral 结果重新核验，不重开检索 | 原始Manassas,VA→US、旧VA留在result-history、revision递增；机构仍no_match、不入选；原spec和1/1入选保留，Wave调用数不增加 |
| 发布 | 全量测试和真实正向用例后提交／正常 push，更新 app Docker | 远端 SHA 与本地一致；容器健康；原数据／浏览器状态保留；提交后的原公网地址再次发送并验证实际报告 |

代码回归执行 Vitest 全量、TypeScript、前端生产构建和五项完整 Playwright E2E。仪器覆盖率与受控场景不作为业务目标完成标准。实际账号／人数／缺额必须由独立真实数据证据记录。

手动验收者可先运行 B，验证开放检索与交付；再运行 A 或从已交付的严格名单打开逐条证据。默认需要登录或验证的浏览器工作，由验收用户在确认后使用 VNC 处理，不让 Agent 输入密码／验证码。
