# 面试反馈补救验证方案

日期：2026-10-13，Asia/Shanghai。

验收必须同时检查交付入口、真实来源、自然语言与最终报告。受控资料和覆盖率只能验证程序行为，不能证明真实名单供给。原题与用户批准的调整口径分别保存、分别统计。

| 场景 | 验证与通过标准 |
|---|---|
| 公网 HTTP 发送 | 在 `http://101.201.237.219:33332/` 的非安全上下文、`crypto.randomUUID` 不存在时，实际点击发送；验证请求、保存的用户消息、后台回复、草稿清空，无页面异常。 |
| 发送失败反馈 | ID 生成或发送异常展示错误、保留草稿；重试复用正确的幂等 ID，不能重复提交研究。 |
| 原题实际效果 | 保留原有开放搜索，读取真实目标、分析人数、合格人数、来源边界与逐项缺口。0/20 必须记为未满足原题交付，不能因诚实交付空集判为原题成功。 |
| 调整口径开放搜索 | 真实 token 与实际模型，通过公网聊天启动新研究；不指定账号、不预埋手选名单。核实保存的查询词、基础读取/分析边界、逐人条件和证据；缺额真实报告。 |
| 所在地事实 | 本人简介中的明确定位符、完整州/省名及明确城市地址保留原文，保守映射国家；受众、旅行、语言、外貌、含糊城市或其他账号不能冒充本人所在地。 |
| 实际视觉证据 | 访问真实媒体，保存截图、来源和真实发表日期；链接或头像不等同于看过本人内容。已观察的视频封面仅支持封面可见特征，不声称已观看视频或取得照片帖。 |
| 选取素材与访问范围 | 近期帖子和本人自我介绍保留对应素材；即使原始证据超过 100 个，模型看见的素材也须优先进入访问范围。证据编号恢复完整签名链接，拒绝其它候选、未知编号和冲突地址。 |
| 执行中用户改偏好 | 公网自然消息更新指定原任务：不改筛选条件、不重复登记；单独持久记录使正在执行的模型返回也遵循最新许可。 |
| 默认人工交接 | 默认允许协助。实际挑战页→Agent 保存阻塞原因→用户明确认领→同一 VNC 桌面暂停 Agent 输入、用户操作→交还→重新观察并继续原候选。不得自动输入密码或声称人工声明等于平台证据。 |
| 本次仅公开资料 | 只对本次任务禁止人工协助；已等待的请求撤销后恢复原候选，访问阻塞保持 unknown。其它任务和默认 VNC 交接不变。 |
| 最终交付 | 任务达到有界来源/分析边界后，chat 自动交付 HTML/CSV；逐人判断、标签、入选、合格人数与数据库一致，待核实不计为合格。公网打开报告及下载 CSV。 |
| 大规模真实报告 | 保留实际35/30人资料，在线不内嵌全部截图，实际滚动加载资产；从公网点击CSV及筛选后的含截图离线HTML下载。研究/Campaign/综合报告人数和证据不因图像交付方式变化。 |
| 大历史查询和摘要 | 保留真实历史规模，在原公网入口查询已结束研究；不能为通过测试清空历史。指定任务结果只加载相关记录；报告、页面和 CSV 显示有效国家事实。记录实际冷压缩、回复等待和失败，不把收到错误答复视为通过。 |
| 实际执行中续聊 | 单独启动小型真实开放文字研究，在 queued/running 时从公网 UI 再发自然消息，核对旧任务不丢失、新任务只登记一次、两条消息处理和真实终态报告。专项候选不混入补救的20人名单。 |
| 核心回归 | 单元/集成/React、类型、Docker 构建；实际配置模型与有头浏览器验证研究/画像/报告、Campaign 交互/去重、原始 Instagram GET、noVNC 及三次重启持久化。明确说明哪些来源受控。 |
| 历史保留 | 部署前 SQLite 私有快照；部署后核对原任务、结果、消息、交付与 Campaign 内容。新研究及其执行偏好之外不得误改历史。 |

输出保留实际失败、阻塞与缺额；不以测试覆盖率、HTTP 200 或受控候选正例替代真实业务结果。
