
# WaveSurge 使用文档

从登录、建项目到找创作者、外联、签约、交付和复盘，WaveSurge 每一步怎么用。

更新于 2026-10-10

## 开始使用

WaveSurge 是一个 AI 创作者营销平台：你用自然语言说清需求，平台帮你出策略、在 TikTok、Instagram、YouTube、X 上找到合适的创作者，然后完成外联、谈判、合同、交付、付款和复盘。所有工作都围绕一个项目（Project）和它的 Campaign 进行。

1. 用 Google 账号登录 https://wavesurge.ai，新账号赠送 58 credits。
2. 首页点「Start your first project」，给项目起个名字，进入 Chat。
3. 在 Chat 里说清品牌官网、投放市场、预算、目标、平台和想找的创作者，也可以直接把资料文件拖进来。
4. 需求够了以后，说一句“创建 Campaign”，或者点「找创作者」开始找人。
5. 在 Creator 里查看名单，在 Rule 里定合作规则，在 Outreach 里发起联系和谈判。
6. 签约后在 Campaigns 里跟踪交付和付款，最后在 Simulation 和 Analytics 里看效果。

| 页面 | 做什么 |
| --- | --- |
| Overview | 当前 Campaign 的预算、发送进度、待付款和需要你处理的事项 |
| Chat | 说需求、上传资料、生成报告、找创作者、改合作规则 |
| Creator | Campaign 的创作者名单：筛选、查看详情、导出、剔除 |
| Rule | 合作规则：付款节点、价格上限、跟进节奏、授权、内容审核流程、Brief 资料 |
| Outreach | 首次联系、回复、报价审批、谈判 |
| Campaigns | 签约后的交付工作台：审阅内容、要求修改、给创作者发消息、付款节点 |
| Simulation | 用谈妥的创作者组合模拟曝光、访问和转化 |
| Analytics | 真实采集到的结果、内容表现和预测对比 |
| Money | 积分余额、流水、费用估算和充值 |

> **项目还没有 Campaign 时**：除 Chat 外的页面都是灰色不可点。先在 Chat 里创建 Campaign，其他页面才会有数据。

## Chat：说需求、出报告

- 你说的每一条需求都保存在项目的 Brief 里，刷新、换设备都还在。聊天会根据你已经说过的话推出相关需求项，先给你核对，你认可的才保存。
- 可以拖入、粘贴或用回形针添加资料：一条消息最多 5 个文件，每个最大 100 MB，支持 PDF、Word、PowerPoint、Excel、CSV、文本和图片。
- 需要你拍板时，输入框上方会弹出选择题；聊天也能自己上网查资料、读网页。
- 策略报告（40 credits / 份）：定位、受众、平台、创作者方向、内容和执行建议。竞品报告（100 credits / 份，不论扫几个竞品）：竞品在各平台的表现和机会。两份报告都不是必需的。
- 竞品要写官网或 X、TikTok、Instagram、YouTube 主页，只写品牌名的那几条不会被扫。
- 报告是横向翻页的幻灯片，可以下载成网页文件或打印成 PDF。输入框旁可以切换报告语言。
- 合作规则也可以直接在聊天里说，比如“付款分三段 30/40/30”“发布后押款 72 小时”。

> **付费前一定会先确认**：聊天不会自己开始付费工作。点「生成策略报告」「找创作者」等按钮后，会弹出「核对并确认」，写明谁付费、多少 credits，你确认后才开始、才扣费。

## Creator：找创作者

- 一次可以给每个平台指定人数：单个平台 1–2000 人，所有平台加起来不超过 5000 人。
- 筛选条件包括创作者画像、市场、语言、粉丝区间、账号类型、排除项、活跃度和是否必须有公开联系方式。
- 搜索在后台运行，通常需要几个小时，不必守着；跑完会通知你。
- 每位交付的创作者都会逐条列出你的条件是否满足、依据和来源链接。
- 交付的创作者会自动附一份粉丝画像（性别、年龄、国家），在卡片视图里显示，不额外收费。
- 名单可以导出卡片 PDF（最多 1000 张）或 Excel（不限人数）。
- 通过 API 获取 Instagram 原始数据并自行筛选时，使用「API 文档 → Instagram 原始用户搜索 API」中的三个 GET 接口。以下交付和收费说明适用于平台内 Campaign 搜索。
- 你也可以上传自己的创作者名单，或手动添加；把创作者从名单里剔除不收费。
- 收费：每位实际交付的创作者 10 credits，加上这次搜索真实产生的调用成本；下单时按订单人数预留，跑完多退少补，没跑成全退。

## Rule、Outreach 与签约交付

- Rule 里定好的规则（付款节点、价格上限、授权、排他、审核流程等）会被外联、谈判和合同共同使用。
- 开始外联时，按可联系的创作者人数收费，每人 6 credits；没人可联系时不扣费。后续跟进和 AI 起草的谈判回复每条 1–1 credits。
- 创作者报价后，AI 只记录事实并等你决定，不会替你接受或还价。
- 谈妥后生成合同，核对交付范围和资金后发出；创作者签署后进入 Campaigns 交付工作台。
- 在 Campaigns 里审阅每一版内容，可以批准或要求修改；内容预审每份 4 credits。
- 所有放款都必须由你核对准确金额并明确批准。
- Campaign 菜单里可以随时暂停或恢复发送。

## 积分与价格

| 动作 | 价格 |
| --- | --- |
| 聊天、改需求、写规则、创建 Campaign、上传资料、查进度 | 免费 |
| 策略报告 | 40 credits / 份 |
| 竞品报告 | 100 credits / 份 |
| 找创作者 | 每位实际交付 10 credits + 本次真实调用成本 |
| 首次外联 | 6 credits / 每位可联系的创作者 |
| 跟进消息 | 1 credits / 条 |
| AI 谈判回复 | 1 credits / 条 |
| 内容预审 | 4 credits / 份 |

- Money 页面显示余额、按动作统计的消费、积分流水和费用估算，并可购买积分包（Card 或 PayPal）。
- 付费任务失败或没跑成时，预留的积分会退回；同一任务重复提交不会重复扣费。
- 创作者费用、平台服务费和 Campaign 预算以美元结算，与 credits 分开。
- 最新价格以 https://wavesurge.ai/api/v1/pricing 为准。

## 团队协作

- 选中 Campaign 后，点项目切换器里的 Team 按钮邀请成员，可一次输入多个邮箱。
- 成员以 Manager 身份加入：可以操作项目，付费动作从项目 Owner 的钱包扣除；Manager 可以自行退出。
- 只有 Owner 可以删除项目和管理成员。
